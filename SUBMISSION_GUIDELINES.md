# Submission Guidelines

## Overview
The final solution must be a public GitHub repository. The root folder of the repository must contain the following three files, which are required for evaluation:

## Required Files

### 1. REASONING.md
- **Purpose**: An explanation of the thought process behind the solution
- **Content**: Should include:
  - Problem understanding and analysis
  - Architecture decisions
  - Implementation approach
  - Key technical choices and rationale
  - Any challenges faced and how they were resolved
  - Testing strategy and verification

### 2. AI_LOGS.md
- **Purpose**: A complete copy of the candidate's conversation with the AI tool (Copilot or any other)
- **Important**: This log must be pasted as-is and not modified in any way
- **Warning**: Any alteration to AI_LOGS.md will lead to a deduction of marks
- **Content**: Full conversation history including all prompts, responses, and code changes

### 3. README.md (or equivalent main documentation)
- **Purpose**: Project documentation and setup instructions
- **Content**: Should include:
  - Project description
  - Features implemented
  - Technology stack
  - Setup and installation instructions
  - Usage guidelines
  - Demo credentials (if applicable)

## Repository Requirements

### Public Access
- Repository must be publicly accessible on GitHub
- Ensure proper permissions are set for evaluators to view the code

### File Structure
```
repository-root/
├── REASONING.md          # Thought process explanation
├── AI_LOGS.md           # Complete AI conversation log (unaltered)
├── README.md            # Project documentation
├── [project files]      # Actual implementation
└── [other documentation]
```

## Submission Checklist

Before submitting, verify:

- [ ] Repository is public on GitHub
- [ ] REASONING.md exists in root folder
- [ ] AI_LOGS.md exists in root folder
- [ ] README.md (or equivalent) exists in root folder
- [ ] AI_LOGS.md is complete and unaltered
- [ ] All required files are in the root folder (not in subdirectories)
- [ ] Repository URL is correctly provided in submission
- [ ] Solution is fully functional and meets all requirements

## Important Notes

1. **AI_LOGS Integrity**: The AI conversation log must be authentic. Any modifications, edits, or truncations will result in mark deductions.

2. **File Location**: All three required files must be in the repository root, not in any subdirectory.

3. **Repository Privacy**: Ensure the repository is set to public. Private repositories cannot be accessed by evaluators.

4. **Documentation Quality**: REASONING.md should demonstrate clear understanding of the problem and justify technical decisions.

5. **Completeness**: Ensure the solution is complete and functional before submission.

## Example AI_LOGS.md Format

The AI_LOGS.md should contain the complete conversation as it occurred, including:
- All user prompts
- All AI responses
- Code snippets
- Tool invocations
- Error messages
- Success confirmations

Do not edit, format, or modify the conversation in any way.

## Final Steps

1. Create the GitHub repository
2. Add all project files
3. Create REASONING.md with your thought process
4. Copy the complete AI conversation to AI_LOGS.md
5. Ensure README.md is comprehensive
6. Set repository to public
7. Verify all three required files are in root
8. Submit the repository URL
